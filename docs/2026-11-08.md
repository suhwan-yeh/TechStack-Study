## 2. Thymeleaf의 th:text와 th:utext 학습

### th:text
- 변수의 값을 일반 텍스트로 출력한다.
- 값에 HTML 태그가 있어도 서식으로 적용하지 않고 글자로 표시한다.
- 개발자가 정해둔 모양에 글자만 넣을 때 사용할 수 있다.

```html
<strong th:text="${message}"></strong>
```

바깥의 strong 태그가 글자를 굵게 만든다.
message 안에 들어 있는 HTML 태그는 글자로 처리된다.

### th:utext
- 변수 안의 HTML 태그를 실제 서식으로 적용해서 출력한다.
- 사용자가 에디터로 꾸민 게시글의 굵은 글씨, 목록, 링크 등을
  화면에 표시해야 할 때 사용할 수 있다.

예를 들어 message에 다음 내용이 들어 있다면:

```html
내일은 <strong>중요</strong>한 발표가 있어요.
```

- th:text: strong 태그까지 글자로 표시한다.
- th:utext: '중요'라는 단어를 굵게 표시한다.

### 보안 — XSS와 Safelist
- XSS는 삽입된 악성 스크립트 등이 사용자의 브라우저에서
  실행될 수 있는 취약점이다.
- 사용자 입력을 정화 없이 th:utext로 출력하면 위험할 수 있다.
- HTML을 허용해야 한다면 서버에서 jsoup 등의 도구로 정화한다.
- Safelist는 허용할 HTML 태그, 속성, URL 규칙 등을 정한다.
- 정화한 HTML을 th:utext로 출력한다.
- th:utext 자체가 위험한 HTML을 자동으로 제거하지는 않는다.

### 오해했던 부분
- th:utext가 굵은 글씨나 읽어주기 전용 기능을 가진 것은 아니다.
- strong 태그 자체가 보안에 취약한 것은 아니다.
- th:text로 출력한 텍스트도 스크린리더가 읽을 수 있다.
- 선택 기준은 기존 내용인지가 아니라,
  변수 안의 HTML을 실제 서식으로 적용해야 하는지다.

### 핵심 정리
기본은 th:text를 사용한다.
내용 안의 HTML 서식이 필요할 때만 정화 후 th:utext를 사용한다.
