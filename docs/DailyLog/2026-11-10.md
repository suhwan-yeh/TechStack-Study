## 발생한 문제와 해결

| 문제 | 원인 | 해결 |
|---|---|---|
| S3 목록 조회 시 AccessDenied | EC2 역할에 ListBucket 권한 부족 | deploy/ 목록 조회 권한 추가 |
| 서비스 파일이 빈 화면으로 표시 | 다른 경로의 파일을 열었음 | /etc/systemd/system/crm.service 경로 확인 |
| 터미널 구문 오류 | 명령 실행 결과를 다시 명령으로 입력 | 출력과 입력 명령을 구분하여 실행 |

## 학습한 내용
- Ubuntu는 서버에 설치된 운영체제
- AWS CLI는 명령어로 AWS 서비스를 사용하는 도구
- IAM 역할은 AWS 자원 접근 권한을 제공
- crm.env는 앱 설정, crm.service는 앱 실행 방식을 관리
- 자동 실행 등록(enable)과 즉시 실행(start)은 별도 작업
