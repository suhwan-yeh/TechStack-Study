## 2. IntelliJ와 Gradle

### IntelliJ IDEA란?

Java 및 Spring Boot 프로젝트를 개발하기 위한 통합 개발 환경(IDE)이다.

코드 작성, 자동 완성, 디버깅, Gradle 빌드, 애플리케이션 실행 등의 기능을 제공한다.

### Gradle이란?

Java 프로젝트의 빌드와 외부 라이브러리 의존성을 관리하는 도구이다.

Spring Boot 프로젝트에서는 `build.gradle`을 통해 필요한 라이브러리를 등록한다.

```gradle
dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
    runtimeOnly 'com.mysql:mysql-connector-j'
}
```

**각 의존성의 역할**

- `spring-boot-starter-data-jpa`: Java 객체와 데이터베이스를 연결하는 JPA 기능 제공
- `mysql-connector-j`: Java 애플리케이션이 MySQL과 통신할 수 있도록 하는 JDBC 드라이버

의존성을 변경했다면 IntelliJ에서 `Reload All Gradle Projects`를 실행하여 프로젝트 설정을 동기화해야 한다.

## 3. OpenRouter API와 AI 글쓰기 도우미

### OpenRouter란?

여러 AI 모델의 API를 하나의 서비스에서 사용할 수 있도록 제공하는 API 플랫폼이다.

일반적인 AI 글쓰기 도우미의 처리 흐름은 다음과 같다.

```text
사용자
  ↓
글쓰기 요청 입력
  ↓
Java 애플리케이션
  ↓
HTTP API 요청
  ↓
OpenRouter
  ↓
선택한 AI 모델
  ↓
AI 응답 반환
  ↓
사용자에게 글쓰기 제안 표시
```

### API란?

서로 다른 프로그램이 정해진 규칙에 따라 데이터를 주고받을 수 있도록 하는 인터페이스이다.

AI API를 사용하면 직접 AI 모델을 학습시키지 않고도 글 생성, 요약, 번역 등의 기능을 애플리케이션에 추가할 수 있다.

### JSON이란?

프로그램 사이에서 데이터를 주고받을 때 사용하는 데이터 형식이다.

예시:

```json
{
  "topic": "여행",
  "tone": "friendly",
  "language": "ja"
}
```

위 데이터는 여행을 주제로 친근한 말투의 일본어 글을 요청하기 위한 예시 입력 데이터이다.

### API 키를 환경변수로 관리하는 이유

API 키는 외부 서비스에 접근하기 위한 인증 정보이므로 소스 코드에 직접 작성하지 않는 것이 좋다.

```properties
spring.datasource.password=${DB_PASSWORD}
```

`${DB_PASSWORD}`는 실제 비밀번호를 코드에 작성하는 대신 실행 환경에서 값을 읽어오도록 하는 설정이다.

**학습 포인트:** 소스 코드와 비밀정보를 분리해야 GitHub에 코드를 올릴 때 인증 정보가 노출되는 위험을 줄일 수 있다.

## 4. AWS Lightsail과 MySQL

### AWS Lightsail이란?

가상 서버를 제공하는 AWS 서비스이다.

이번 개인 프로젝트에서는 Ubuntu 서버를 구축하고 MySQL을 설치하여 원격 데이터베이스 환경을 구성했다.

### MySQL이란?

데이터를 테이블 형태로 저장하고 SQL을 통해 조회·추가·수정·삭제할 수 있는 관계형 데이터베이스 관리 시스템(RDBMS)이다.

### 개발 DB와 운영 DB 분리

| 구분 | 데이터베이스 | 용도 |
|---|---|---|
| 개발 | `ponpon_studio` | 기능 구현 및 테스트 |
| 운영 | `ponpon_studio_prod` | 실제 서비스 데이터 관리 |

개발 DB와 운영 DB를 분리하는 이유는 테스트 과정에서 운영 데이터가 변경되거나 삭제되는 사고를 방지하기 위해서이다.

현재 두 DB는 같은 MySQL 서버에 있으므로 서버 장애까지 분리되는 것은 아니다.

### MySQL 실행 상태 확인

```bash
sudo systemctl status mysql
```

### MySQL TCP 포트 확인

```bash
sudo ss -lntp | grep 3306
```

확인한 결과 MySQL은 `127.0.0.1:3306`에서 연결을 기다리고 있었다.

## 5. SSH 터널을 통한 원격 MySQL 연결

### SSH 터널이란?

SSH 연결을 통해 네트워크 통신을 암호화하여 전달하는 방식이다.

이번 프로젝트에서는 학원 PC의 Spring Boot 애플리케이션이 AWS MySQL에 안전하게 접속하도록 SSH 로컬 포트 포워딩을 사용했다.

```text
학원 PC
Spring Boot
127.0.0.1:3307
       ↓
SSH 터널
       ↓
AWS Lightsail
127.0.0.1:3306
       ↓
MySQL
ponpon_studio
```

### SSH 터널 명령어

```powershell
ssh -i "SSH개인키경로" -N -L 127.0.0.1:3307:127.0.0.1:3306 ubuntu@서버공인IP
```

**옵션 설명**

- `-i`: SSH 개인키 지정
- `-N`: 서버에서 별도 명령을 실행하지 않고 연결 유지
- `-L`: 로컬 포트를 원격 서버의 특정 포트로 전달

### 연결 확인

```powershell
Test-NetConnection 127.0.0.1 -Port 3307
```

결과:

```text
TcpTestSucceeded : True
```

이 결과는 학원 PC의 3307 포트에서 TCP 연결이 가능하다는 의미이다.

단, 이것만으로 MySQL 로그인까지 성공했다는 뜻은 아니다.

### 발생한 오류와 해결

**오류**

```text
Communications link failure
Connection refused
```

**원인**

Spring Boot 실행 당시 SSH 터널이 종료되어 로컬 포트 3307로 연결할 수 없었다.

**해결 과정**

1. AWS MySQL 서비스 실행 상태 확인
2. MySQL의 3306 포트 LISTEN 상태 확인
3. AWS 서버 내부에서 MySQL 계정 로그인 성공 확인
4. SSH 터널 재실행
5. 로컬 3307 포트 연결 성공 확인
6. Spring Boot 재실행

**배운 점:** 데이터베이스 연결 오류가 발생했을 때 무작정 코드를 수정하기보다 서버, 포트, 인증, 애플리케이션 설정을 단계적으로 확인해야 한다.

## 6. Spring Boot와 MySQL 연결

### application.properties

```properties
spring.datasource.url=jdbc:mysql://127.0.0.1:3307/ponpon_studio
spring.datasource.username=ponpon_app
spring.datasource.password=${DB_PASSWORD}

spring.jpa.hibernate.ddl-auto=none
spring.jpa.show-sql=true
```

### 주요 설정 의미

| 설정 | 역할 |
|---|---|
| `datasource.url` | MySQL 접속 주소 |
| `datasource.username` | DB 계정 |
| `datasource.password` | 환경변수에서 비밀번호 읽기 |
| `ddl-auto=none` | Hibernate의 자동 스키마 변경 비활성화 |
| `show-sql=true` | Hibernate가 생성하는 SQL 출력 |

### HikariCP란?

Spring Boot에서 데이터베이스 연결을 관리하는 커넥션 풀이다.

데이터베이스에 접근할 때마다 연결을 새로 생성하는 대신, 연결을 재사용하여 효율적으로 관리할 수 있다.

성공 로그:

```text
HikariPool-1 - Start completed.
```

## 7. JdbcTemplate을 이용한 실제 DB 연결 테스트

### 테스트 코드

```java
package com.ponpon.studio.example;

import org.springframework.boot.CommandLineRunner;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.stereotype.Component;

@Component
public class DatabaseConnectionTest implements CommandLineRunner {

    private final JdbcTemplate jdbcTemplate;

    public DatabaseConnectionTest(JdbcTemplate jdbcTemplate) {
        this.jdbcTemplate = jdbcTemplate;
    }

    @Override
    public void run(String... args) {
        String dbName = jdbcTemplate.queryForObject(
                "SELECT DATABASE()", String.class
        );

        System.out.println("연결된 DB: " + dbName);
    }
}
```

### 코드 핵심 개념

**`@Component`**

Spring이 해당 클래스를 Bean으로 등록하고 관리하도록 한다.

**`CommandLineRunner`**

Spring Boot 애플리케이션이 시작되는 과정에서 `run()` 메서드를 실행할 수 있도록 한다.

**생성자 주입**

```java
public DatabaseConnectionTest(JdbcTemplate jdbcTemplate) {
    this.jdbcTemplate = jdbcTemplate;
}
```

Spring이 관리하는 `JdbcTemplate` 객체를 생성자를 통해 전달받는다.

**`queryForObject()`**

SQL을 실행하고 단일 결과를 지정한 Java 타입으로 반환받는다.

### 실제 실행 결과

```text
연결된 DB: ponpon_studio
```

이 결과를 통해 Java 애플리케이션에서 AWS MySQL까지 실제 SQL 요청과 응답이 정상적으로 이루어졌음을 확인했다.
