## 학습한 내용
- CI는 빌드·테스트를 자동화하고, CD는 실행 파일 전달과 서버 실행을 자동화함
- S3는 배포 파일 보관, EC2는 앱 실행을 담당함
- GitHub Actions는 IAM 사용자 키로 S3에 업로드함
- EC2는 연결된 IAM 역할로 S3에서 다운로드함
- SSH 개인키는 접속 자격을 증명하고, 서버 공개키는 접속 대상의 신원을 확인함
- Secrets는 등록만으로 동작하지 않고 워크플로에서 참조해야 함
- 운영의 ddl-auto=validate는 테이블을 생성하지 않고 구조만 검사함
- 배포용 커밋 타입은 팀 규칙에 따라 ci(deploy)를 사용함
